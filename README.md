# Flappy Kitty

Игра про кошку Мию, которая научилась летать. Подарок для Насти.
Домен: **flappykitty.online**

Это обычный статический сайт: HTML, CSS и JavaScript без сборки и без внешних сервисов. Его можно открыть с любого хостинга, в том числе с GitHub Pages.

| --- | --- |
| Владельцу | этот файл и [docs/PLAN.md](docs/PLAN.md) — что осталось сделать руками |
| ИИ-агенту с доступом к репозиторию | [AGENTS.md](AGENTS.md) — правила, карта кода, проверки; [docs/PROJECT.md](docs/PROJECT.md) — где мы сейчас и почему так; очередь задач — во второй части [docs/PLAN.md](docs/PLAN.md) |

## Что внутри

**Игра** (`play.html`) — Flappy Bird, но добрее и длиннее:

- **Два уровня, в каждом десять раундов.** Всего двадцать раундов, у каждого свой мир, свои колонны и своя хитрость.
  - Уровень 1 «Первая дорога»: Гостиная, Кухня, День рождения, Ночной город, Зимняя сказка, Под дождём, Лягушачий пруд, Плюшевый совет, Поцелуй или кусь, Дорога к Насте.
  - Уровень 2 «Вторая дорога»: Чердак, Робот-пылесос, Корзинка с нитками, Ванная, Двор, Пекарня, Ящик с игрушками, Камин, Гроза, Дорога к Насте · рассвет.
- **Двадцать записок и два письма.** После каждого раунда Мия оставляет записку. После десятого раунда уровня она отдаёт ещё и письмо в запечатанном конверте — оно уже не от Мии, а от тебя.
- Хитрости раундов: капли из крана, шарики с сердечками, летающие огурцы, ветер, дождь из тучек, прыгучие лягушата, клубки, летучие мыши, подвижные ворота; во втором уровне — комки пыли навстречу, робот-пылесос, который тянет вниз, мыльные пузыри, голуби, пар (подбрасывает) и булочки, солдатики, угольки и молнии, от которых нужно нырять.
- Десятый раунд каждого уровня — самый длинный: примерно вдвое длиннее предыдущего.
- 3 жизни на раунд вместо мгновенного проигрыша.
- Сердечки — общая валюта. Бонусы: пузырь, магнит, кошачья мята.
- 3 звезды за раунд: долетела, собрала 70% сердечек, не потеряла жизней.
- Гардероб из 6 обликов, вырезанных из настоящих фотографий Мии.
- Бесконечный режим с рекордом (открывается после первого раунда): мир меняется каждые шесть ворот, в каждом — свой обитатель из сюжета. Порядок миров в каждом забеге свой; миры второго уровня появляются, когда он открыт.
- У каждого мира своя музыка; всё звучит из кода, без единого аудиофайла.
- В день рождения игра поздравляет сама.
- Звуки и музыка синтезируются в браузере, аудиофайлов нет. Выключаются одной кнопкой в меню или по отдельности на паузе.
- Работает на телефоне (тап) и на компьютере (пробел, стрелка вверх, клик; пауза — Esc).
- Собранные сердечки не пропадают, даже если выйти из раунда через паузу или закрыть вкладку.
- Отклик на каждое действие: Мия вытягивается на взмахе и сплющивается от удара, собранные сердечки летят к счётчику, десять сердечек подряд дают премию +2, пролёт впритирку к воротам высекает искры, удар на мгновение останавливает кадр. На сложность это не влияет.
- Музыка меняется по ходу раунда: к финишу добавляются слои, на последней жизни она настораживается, у письма — своя тихая мелодия.
- Письмо приходит в запечатанном конверте с именем. Его открывают касанием печати; строки появляются одна за другой, на фоне поднимаются сердечки.
- К каждой записке и к письму приклеена настоящая фотография Мии из альбома.
- В меню Мию можно потрогать: она мяукает, мурчит и отвечает репликой.
- После первого открытия игра запускается и без интернета, экран телефона во время полёта не гаснет.

## Запуск на своём компьютере

Нужен Node.js 18 или новее (или Python 3).

```bash
git clone https://github.com/miagpt/flappykitty.online.git
cd flappykitty.online
npm start
```

Открой <http://localhost:8000>. Без Node.js подойдёт `python3 -m http.server 8000`. Просто открыть `index.html` двойным щелчком не получится: браузер не загружает JavaScript-модули с диска.

`npm run start:pages` поднимает сайт в подпапке, по адресу <http://localhost:8000/flappykitty.online/> — так, как он будет лежать на `github.io` до подключения домена.

Полезные адреса для проверки:

- `play.html?dev=1` — все раунды и бесконечный режим открыты сразу;
- `play.html?round=4` — сразу четвёртый раунд (если он уже открыт); номер — сквозной, от 1 до 20: `?round=13` — третий раунд второго уровня. Старый адрес `?level=4` работает так же;
- `play.html?reset=1` — стереть прогресс на этом устройстве (спросит подтверждение);
- `love.html?peek=1` — все записки и оба письма видны без прохождения.

## Что поправить перед тем, как дарить

Всё личное лежит в одном файле — **`assets/js/config.js`**. Код игры трогать не нужно.

1. **`notes`** — двадцать записок, по одной после каждого раунда (`round` — сквозной номер раунда, от 1 до 20). Записки с пометкой «черновик агента» стоит переписать: добавь в них то, что знаете только вы двое. Записки № 10 и № 20 — те, которыми Мия передаёт письма; их текст уже твой.
2. **`letters`** — два письма, по одному в конце каждого уровня (`level: 1` и `level: 2`). Тексты уже твои; это главное место в игре, перечитай их ещё раз.
3. **`birthday`** — дата праздничного режима. Сейчас стоит 3 сентября: дата взята с фотографии из архива и может быть неверной.
4. **`from`** — подпись под письмом. Сейчас «Твой ❤», можно вписать имя. Знак ❤ на странице заменяется нарисованным сердечком.

Проверить, как выглядят тексты: `love.html?peek=1`.

### Проверки

```bash
npm test
```

Занимает около минуты, ничего устанавливать не нужно. Внутри три проверки:

| Команда | Что делает |
| --- | --- |
| `npm run test:unit` | Правила игры и сохранение: физика, жизни, звёзды, записки, новые обитатели раундов, перенос старых сохранений, битые данные в браузере |
| `npm run test:site` | Целостность сайта: битые ссылки и картинки, потерянные `id`, внешние ресурсы. Сверяет с игрой числа в текстах страниц: уровней, раундов, записок и писем. Заодно напоминает про `mia.zip` |
| `npm run test:bot` | Сложность. Бот проходит каждый раунд 150 раз на узком и широком экране и печатает долю побед, потерянные жизни и длительность. Падает, если какой-то раунд бот проходит реже чем в 85% случаев |

Сейчас бот выигрывает от 90% до 100% забегов на каждом раунде. Обычный раунд длится 23–33 секунды, последний раунд уровня — около минуты; оба уровня — примерно одиннадцать минут чистого полёта. Бот летит по центру просвета и не видит опасностей (капли, огурцы, лягушат, летучих мышей, пузыри, голубей, булочки, солдатиков, угольки, молнии), поэтому человеку, который их видит, немного проще, чем показывают цифры. Запускай `npm test` после любой правки в `levels.js`.

Четвёртая проверка открывает сайт в настоящем браузере и проходит игру: меню, полёт, пауза, победа, проигрыш, записки, письмо, гардероб, звук, страница 404, четыре ширины экрана. Ей нужны библиотеки, которых нет в репозитории:

```bash
npm i --no-save --ignore-scripts puppeteer-core @sparticuz/chromium
npm run test:e2e
```

На GitHub обе группы проверок запускаются сами на каждый pull request и на каждый коммит в `main` (вкладка **Actions**, проверки «npm test» и «браузер»).

Чего проверки не заменяют: настоящий телефон. Звук, вибрацию, жесты и значок на экране «Домой» нужно один раз посмотреть руками — список в [docs/PLAN.md](docs/PLAN.md), час 6.

## Публикация

Порядок такой: сначала сайт проверяется на адресе GitHub Pages, потом к нему подключается домен.

### Перед публикацией: архив `mia.zip`

GitHub Pages раздаёт всё, что лежит в ветке. Пока `mia.zip` в репозитории, его сможет скачать любой по адресу `…/mia.zip`, а в архиве есть личные снимки, которых нет на сайте. Сайту архив не нужен: все нужные картинки уже лежат в `assets/img/`. Сохрани архив у себя и удали из репозитория:

```bash
git rm mia.zip
git commit -m "Убрать архив с исходными фото"
git push
```

Файл останется в истории коммитов. Пока репозиторий закрытый, история никому не видна.

> **Состояние сейчас.** Архив из ветки удалён, сайт его не раздаёт. Но репозиторий открыт, а в истории коммитов архив остался: кто знает адрес старого коммита, может его скачать. **Это ещё не исправлено** — ниже, как исправить.

#### Как убрать архив совсем

Архив лежит в истории **трёх** открытых репозиториев: `miagpt/flappykitty.online` (этот), `miagpt/flappy` (тестовая копия) и `RUUSA-SHOP/flappykitty.online2` (из него сделана тестовая копия). Убирать нужно во всех трёх.

Почему этого не сделал агент. Переписать историю ветки `main` недостаточно: GitHub хранит старые коммиты по ссылкам закрытых pull request (первый из них начинается прямо с коммита с архивом), и стереть их может только поддержка GitHub или удаление репозитория. Удалять репозитории и менять их видимость агент не вправе — это настройки владельца. А закрыть этот репозиторий на бесплатном тарифе нельзя: вместе с ним выключится сайт.

1. **Тестовые репозитории — удалить.** Сайту они не нужны: всё их содержимое уже здесь. В каждом из двух: **Settings → General → Danger Zone → Delete this repository**. Если жалко удалять — там же **Change visibility → Private**.
2. **Этот репозиторий — пересоздать из текущего состояния.** Сначала сохранить чистую копию без истории:

   ```bash
   git clone --depth 1 https://github.com/miagpt/flappykitty.online.git clean
   cd clean
   rm -rf .git
   git init -b main
   git add -A
   git commit -m "Flappy Kitty"
   ```

   Затем на GitHub: удалить старый репозиторий (**Settings → Danger Zone → Delete this repository**), создать новый пустой с тем же именем `flappykitty.online` и отправить в него чистую копию:

   ```bash
   git remote add origin https://github.com/miagpt/flappykitty.online.git
   git push -u origin main
   ```

   После этого заново включить Pages (шаг 1 ниже). Адрес сайта останется прежним, сохранения в телефоне тоже: они хранятся в браузере, а не в репозитории. Сайт будет недоступен несколько минут — между удалением и первой публикацией.
3. **Проверить.** В новом репозитории один коммит, и на вкладке **Pull requests** пусто.

Другой путь, если хочется сохранить историю коммитов: `git filter-repo --path mia.zip --invert-paths`, принудительный push всех веток и письмо в поддержку GitHub с просьбой стереть недостижимые коммиты и ссылки закрытых pull request. Он дольше и зависит от поддержки.

### Шаг 1. GitHub Pages

1. Открой в репозитории **Settings → Pages**.
2. **Source**: Deploy from a branch. **Branch**: `main`, папка `/ (root)`. Нажми **Save**.
3. Через минуту-две сайт появится на `https://miagpt.github.io/flappykitty.online/`.

Это нужно сделать руками: у ИИ-агентов нет доступа к настройкам Pages.

Вместе с сайтом публикуется всё содержимое ветки: `README.md`, `AGENTS.md`, папки `docs/` и `tools/`. Секретов в них нет, но и личного туда класть не стоит.

Репозиторий открыт, Pages включён, сайт работает по адресу выше. Для справки: на бесплатном тарифе GitHub Pages работает только для открытых репозиториев, для закрытых нужен платный тариф (Pro для личного аккаунта, Team для организации). Варианты: оплатить тариф или открыть репозиторий в **Settings → General → Change visibility**. Если будешь открывать — сначала прочитай раздел про `mia.zip` выше: в открытом репозитории видна и история. Сам сайт на Pages виден всем в любом случае.

Проверь сайт на телефоне и компьютере. Все пути в проекте относительные, так что он одинаково работает и в подпапке на `github.io`, и в корне своего домена.

### Шаг 2. Домен flappykitty.online (Porkbun)

1. На porkbun.com: **Account → Domain Management**, у домена `flappykitty.online` нажми **DNS**.
2. Удали записи, которые Porkbun создал по умолчанию для страницы-заглушки (обычно это `ALIAS` и `CNAME`, указывающие на `pixie.porkbun.com`).
3. Добавь записи:

   | Type | Host | Answer |
   | --- | --- | --- |
   | A | *(пусто)* | `185.199.108.153` |
   | A | *(пусто)* | `185.199.109.153` |
   | A | *(пусто)* | `185.199.110.153` |
   | A | *(пусто)* | `185.199.111.153` |
   | CNAME | `www` | `miagpt.github.io` |

4. На GitHub: **Settings → Pages → Custom domain**, впиши `flappykitty.online`, нажми **Save**. GitHub сам добавит в ветку файл `CNAME`.
5. Дождись зелёной галочки проверки DNS. Обычно это от нескольких минут до часа, иногда до суток.
6. Когда станет доступна галочка **Enforce HTTPS** — включи её. Сертификат GitHub выпускает сам, это бесплатно.
7. Поменяй адрес в превью для мессенджеров: `node tools/set-url.mjs https://flappykitty.online/`, затем закоммить изменённые страницы. Пока домен не подключён, в превью стоит адрес GitHub Pages — иначе ссылка в Telegram или WhatsApp показывалась бы без картинки.

Адреса в таблице — серверы GitHub Pages. Если запись не сохраняется или проверка не проходит, сверь их с [документацией GitHub](https://docs.github.com/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site).

После подключения домена адрес `miagpt.github.io/flappykitty.online/` начнёт перенаправлять на `flappykitty.online`.

### Поисковики

На всех страницах стоит `<meta name="robots" content="noindex">`: сайт личный, и в поиске ему делать нечего. Если захочешь, чтобы он находился, — убери эту строку из `<head>` каждой страницы.

## Вселенная Мии: что дальше

Flappy Kitty — первая игра. Идея в том, что Мия примеряет разные жанры, а сердечки, облики и записки остаются общими. Для этого уже сейчас прогресс хранится в одном месте (`storage.js`), а личные тексты — в одном файле (`config.js`).

| Игра | Жанр | О чём |
| --- | --- | --- |
| **Flappy Kitty** | аркада | Готова |
| **Super Mia World** | платформер, как Mario | Прыжки по полкам и когтеточкам. Вместо монет — рыбки, вместо грибов — огурцы. В конце мира ждёт Настя с лакомством |
| **The Mims** | симулятор жизни, как The Sims | Шкалы сна, еды, игр и обнимашек. Квартиру можно обставлять |
| **Grand Theft Tuna** | вид сверху, как первые GTA | Ночная квартира. Стащить тунца, скинуть стакан, не разбудить хозяйку. Транспорт — робот-пылесос |
| **Mia Kart** | гонки | Роботы-пылесосы, трассы по комнатам, режим на двоих |

Как добавлять игру:

1. Новая страница рядом с `play.html`, например `super.html`, и своя папка `assets/js/super/`.
2. Сердечки и облики брать из `storage.js` — тогда купленное в одной игре работает в другой.
3. Записки новой игры добавить в `config.js` отдельным списком.
4. Карточку на `worlds.html` перевести из «В планах» в «Уже вышла» и добавить кнопку.

Подробный порядок и первые задачи для «Super Mia World» — в [AGENTS.md](AGENTS.md) и во второй части [docs/PLAN.md](docs/PLAN.md).

Идеи для самой Flappy Kitty: новогодний раунд, ежедневное задание, таблица рекордов на двоих, установка на телефон как приложения с игрой без интернета.
